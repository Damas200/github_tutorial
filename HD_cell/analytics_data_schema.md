
# QuickPoll Analytics Data Schema

## Overview

This document describes the analytics data schema generated by the Data Engineering pipeline for the QuickPoll application.

The ETL pipeline transforms operational data from the transactional database into analytics datasets optimized for reporting and dashboards.

Source tables:

- users
- polls
- poll_options
- votes

Analytics tables produced:

- analytics_poll_summary
- analytics_vote_trends
- analytics_user_participation
- etl_pipeline_runs


---

# Source Schema

## users

Stores user account information.

| Column | Type | Description |
|------|------|-------------|
| id | UUID | Unique identifier for the user |
| email | TEXT | User email address |
| password | TEXT | Hashed user password |
| full_name | TEXT | User full name |
| role | TEXT | User role (ADMIN / USER) |
| created_at | TIMESTAMP | Account creation time |
| updated_at | TIMESTAMP | Last profile update |

---

## polls

Stores poll information created by users.

| Column | Type | Description |
|------|------|-------------|
| id | UUID | Unique poll identifier |
| title | TEXT | Poll title |
| description | TEXT | Poll description |
| status | TEXT | Poll status (OPEN / CLOSED) |
| creator_id | UUID | User who created the poll |
| multi_select | BOOLEAN | Whether multiple options are allowed |
| created_at | TIMESTAMP | Poll creation timestamp |
| updated_at | TIMESTAMP | Poll update timestamp |
| expires_at | TIMESTAMP | Poll expiration timestamp |

---

## poll_options

Options available in a poll.

| Column | Type | Description |
|------|------|-------------|
| id | UUID | Option identifier |
| poll_id | UUID | Poll reference |
| option_text | TEXT | Option label |

---

## votes

Records votes cast by users.

| Column | Type | Description |
|------|------|-------------|
| id | UUID | Vote identifier |
| poll_id | UUID | Poll reference |
| option_id | UUID | Selected option |
| user_id | UUID | User who voted |
| created_at | TIMESTAMP | Vote timestamp |

---

# Analytics Schema

The following tables are generated by the analytics ETL pipeline.

---

## analytics_poll_summary

Poll-level aggregated voting metrics.

| Column | Type | Description |
|------|------|-------------|
| poll_id | UUID | Poll identifier |
| title | TEXT | Poll title |
| creator_name | TEXT | Poll creator |
| total_votes | INTEGER | Total number of votes |
| created_at | TIMESTAMP | Poll creation time |
| etl_run_at | TIMESTAMP | ETL execution timestamp |

Use case:

- dashboard poll overview
- popular polls ranking

---

## analytics_vote_trends

Daily voting activity.

| Column | Type | Description |
|------|------|-------------|
| vote_date | DATE | Date of votes |
| votes_per_day | INTEGER | Number of votes cast |
| etl_run_at | TIMESTAMP | ETL execution timestamp |

Use case:

- voting activity trends
- engagement charts

---

## analytics_user_participation

User voting participation statistics.

| Column | Type | Description |
|------|------|-------------|
| voter_name | TEXT | User name |
| total_votes_cast | INTEGER | Total votes cast |
| participation_rate | FLOAT | Share of votes cast |
| etl_run_at | TIMESTAMP | ETL execution timestamp |

Use case:

- user engagement metrics
- active voter analysis

---

# Pipeline Metadata

## etl_pipeline_runs

Tracks ETL pipeline executions.

| Column | Type | Description |
|------|------|-------------|
| id | SERIAL | Run identifier |
| pipeline_name | TEXT | Pipeline name |
| run_started_at | TIMESTAMP | Start time |
| run_finished_at | TIMESTAMP | End time |
| status | TEXT | success / failed |
| rows_processed | INTEGER | Number of rows processed |
| duration_seconds | FLOAT | Pipeline execution duration |

Use case:

- pipeline monitoring
- debugging ETL failures
- operational analytics

---

# Data Flow

```

users
polls
poll_options
votes
↓
ETL Pipeline
↓
analytics_poll_summary
analytics_vote_trends
analytics_user_participation

```

---

# Notes

- The ETL pipeline supports incremental processing based on the latest vote timestamp.
- Analytics tables are designed for reporting and dashboard consumption.
- The schema aligns with backend entity models to ensure compatibility.
